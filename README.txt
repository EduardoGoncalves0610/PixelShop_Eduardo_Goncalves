PIXELSHOP

Projeto de gestão de loja de jogos e acessórios.

Estrutura:
- com.pixelshop.modelo
- com.pixelshop.testes
- com.pixelshop

Tecnologias:
- Java 17
- Maven

Para abrir no IntelliJ IDEA:
1. Extraia o arquivo ZIP.
2. Abra a pasta PixelShop_Eduardo_Goncalves no IntelliJ IDEA.
3. Aguarde o carregamento do Maven.
4. Execute com.pixelshop.App.
